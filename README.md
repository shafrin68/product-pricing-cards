# Responsive Product Pricing Cards

## About the Project
This project is a responsive product pricing page created using HTML, CSS, and JavaScript. It displays three pricing plans: Starter, Pro, and Team.

## Features
- Monthly and Yearly Pricing Toggle
- Three Pricing Plans
- Responsive Design
- Hover Effects and Animations
- Popular Plan Highlight
- Mobile-Friendly Layout

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Project Structure
- index.html
- style.css
- app.js

## How It Works
Users can switch between monthly and yearly billing options to view different prices. The pricing cards adjust to different screen sizes.
